Project 01

3D 触觉重定向

项目简介

VR中用户伸手抓取虚拟方块时，现实中的物理方块可能位于另一个位置。如果采用1:1映射，视觉中的抓取动作将无法获得对应的触觉反馈。 3D触觉重定向在用户无感知的情况下微调手部运动路径，使虚拟抓取位置与现实物理位置重新对齐。 通过动态调整虚拟与现实之间的空间映射关系，同一物理代理可对应多个虚拟交互位置，从而扩展单一实体道具的使用范围。

我的工作：Unity VR交互原型开发

  • 设计物理方块追踪方案（ArUco Marker + 深度相机）
  • 实现现实空间与 Unity 虚拟空间坐标映射
  • 基于 PICO 4 + OpenXR 实现 VR 交互逻辑
  • 将重定向算法接入 Unity，完成可体验的 VR 交互原型

未来展望

多场景XR体验部署：通过统一规格的物理代理覆盖不同虚拟场景中的交互需求，减少实体道具重复制作与布置成本。 场景切换主要依赖软件配置与空间映射调整，更适用于娱乐、教育培训、工业模拟等需要高沉浸交互的XR应用。

居家XR交互：未来用户无需依赖专用触觉设备，可通过系统注册环境中的日常物体，将其作为临时物理代理，实现低成本、自然化的XR交互体验。

Project 03

实时渲染管线实践

基于 OpenGL 实现实时阴影渲染，支持 PCF 软阴影与双 Pass 渲染流程

项目简介

基于 OpenGL + C++ 实践实时渲染核心流程，围绕空间变换、Shader 编程与光照计算，建立 Unity XR 开发所需的图形学基础。

核心模块

Shadow Mapping — 基于 GLSL 实现 Phong 光照模型与基于深度贴图的实时阴影渲染管线，支持 PCF 软阴影与双 Pass 渲染。

Ray Tracing — 实现光线追踪器，构建 BVH 层次包围盒加速结构与材质系统。

QEM 网格简化 — 基于 Quadric Error Metrics 实现边坍缩网格简化算法。

我的工作

  • 实现 Phong 与 Shadow Mapping 着色器（GLSL），完成实时阴影渲染流程
  • 实现 Model / View / Projection 空间变换矩阵及双 Pass 渲染流程
  • 实现基于 BVH 加速的光线追踪器，支持多种几何体与材质
  • 实现基于 QEM 的网格简化算法，支持按比例控制模型面数
