Project 01

3D 触觉重定向

一句话概述

将现实中的物理方块映射到VR环境，使用户能够在虚拟世界中自然抓取并感受到真实的触觉反馈。

我的贡献

  • 基于 ArUco 标记 + 深度相机搭建物理方块追踪方案
  • 完成现实坐标系 → Unity 虚拟空间的完整坐标映射
  • 实现 VR 交互逻辑与 PICO + OpenXR 设备适配
  • 设计候选过滤的事件驱动架构，替代逐帧轮询
  • 协程分帧处理重定向计算与场景过渡，保障72fps稳定运行

技术挑战

相机空间 → 世界空间 → 物理交互空间的三层坐标转换链；候选过滤在精度与性能之间的阈值设计； VR场景下GC控制与帧率稳定性保障。

未来展望

当前方案依赖统一规格的物理代理（四柱基座 + 标准方块），适合线下门店统一部署。 下一步想探索的是居家场景的去标准化：用户在系统指引下，随手拿起桌边的水杯、书本、遥控器， 放置在指定位置——由系统实时注册为临时物理代理。不同形状的日常物品被映射到不同虚拟交互点上， 实现「无需专用硬件，家里的东西就是你的触觉道具」。这让触觉重定向从商业场馆走向普通家庭， 是VR触觉普及的关键一步。
